사용 안내 / Help

  • 인분, 총 반죽 양 또는 총 밀가루 양으로 계산합니다. 밀가루 재료를 표시하면 원본의 베이커스 퍼센트를 볼 수 있습니다. / Scale by servings, total dough or total flour. Mark flour to see the original baker percentages.
  • 그램은 소수 최대 둘째 자리로 반올림합니다. 부피, 온도, 발효 시간은 변환하지 않습니다. / Grams round to up to two decimal places. Volume, temperature and fermentation time are not converted.
  • 앱 삭제 전에 모든 레시피를 JSON으로 백업하세요. 가져오기는 확인 후 현재 레시피 전체와 언어 설정을 교체합니다. / Back up all recipes as JSON before uninstalling. Import replaces every recipe and the language setting after confirmation.
  • 계량 체크는 계산 변경이나 화면 종료 시 초기화됩니다. / Weighing checks reset when the calculation changes or you leave the screen.
