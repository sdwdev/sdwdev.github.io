이 웹사이트의 개인정보 처리

이 사이트(sdwdev.github.io)는 GitHub Pages로 제공됩니다. GitHub는 호스팅 운영과 보안을 위해 방문자의 IP 주소와 요청 기록을 처리할 수 있으며, 이에는 GitHub 개인정보처리방침이 적용됩니다.

글꼴(Pretendard)은 jsDelivr CDN에서 불러오므로, 페이지를 열 때 브라우저가 jsDelivr에 통상적인 요청 정보(IP 주소 등)를 보냅니다. 이 사이트에는 회원가입이나 입력 양식이 없고, 별도의 방문 분석 스크립트를 사용하지 않습니다.

광고(Google 애드센스)

홈, 앱, 소식, 소개, 이 개인정보처리방침 페이지와 말모아·배터리 리포트 소개 페이지에는 Google 애드센스 광고가 표시될 수 있습니다. 앱별 개인정보처리방침 문서와 여행발자국·BatchNote 지원 페이지에는 광고를 넣지 않습니다.

Google을 포함한 제3자 광고 사업자는 쿠키와 기기 식별 정보를 사용해, 방문자가 이 사이트나 다른 웹사이트를 방문한 기록을 바탕으로 광고를 게재하고 광고 성과를 측정할 수 있습니다. 이 과정에서 IP 주소, 브라우저 정보, 방문한 페이지 정보가 Google에 전달됩니다. 자세한 내용은 Google이 파트너 사이트의 정보를 사용하는 방식과 Google 개인정보처리방침을 참고하세요.

방문자는 Google 내 광고 센터에서 맞춤 광고를 끌 수 있고, aboutads.info에서 다른 제3자 광고 사업자의 맞춤 광고 쿠키를 거부할 수 있습니다. 브라우저 설정에서 쿠키를 차단하거나 삭제할 수도 있습니다. 개발자는 광고 쿠키로 수집된 정보를 직접 받거나 보관하지 않습니다.
